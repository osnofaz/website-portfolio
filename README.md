<h2>Description</h2>
Personal portfolio site built with React, showcasing my work as a Frontend Developer and Graphic Designer. Originally built in 2022 to learn React, and actively maintained since — including a full migration to React 18, dependency modernization, and ongoing performance and accessibility improvements.
<br />

<h2>Features</h2>

- <b>Bilingual</b> — English and Portuguese, via <code>react-i18next</code>
- <b>Light &amp; dark theme</b> toggle, fully theme-aware color system
- <b>Project showcase</b> with a swiper carousel and filterable search
- <b>Downloadable CV</b>, rendered in-page via <code>react-pdf</code>
- <b>Live Twitch embed</b> for stream status
- <b>Fully responsive</b>, mobile-first layout

<h2>Tech Stack</h2>

- <b>React 18</b>
- <b>React Router v7</b>
- <b>styled-components</b>
- <b>react-i18next</b> (i18n)
- <b>react-bootstrap</b>
- <b>Swiper</b>
- <b>react-pdf</b>
- <b>EmailJS</b> (contact form)

<h2>Running Locally</h2>

```bash
git clone https://github.com/osnofaz/website-portfolio.git
cd website-portfolio
npm install --legacy-peer-deps
npm start
```

Runs at <code>http://localhost:3000</code>.
